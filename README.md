# Third-Party API Health Tracker

A production-grade Spring Boot application for monitoring third-party API health, detecting anomalies, and generating AI-powered insights.

## 🚀 Quick Start

### Prerequisites
- **Java 21** (OpenJDK or Eclipse Temurin)
- **Docker** and **Docker Compose**
- **Gradle 8.x** (included via wrapper)
- **PostgreSQL 15+** (via Docker)
